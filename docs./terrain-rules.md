# Scout Terrain Classification Rules

## Status

Draft v0.1

## Terrain 0

Criteria:

- Slope < 10°
- Road distance < 500m
- Settlement distance < 1km

## Terrain 1

Criteria:

- Slope between 10° and 20°
- Road distance between 500m and 2000m
- Settlement distance between 1km and 5km

## Terrain 2

Criteria:

- Slope > 20°
- Road distance > 2000m
- Settlement distance > 5km

## Data Sources

- OS Terrain 50
- OS Open Roads
- OS Open Names
- OS Maps API

## Notes

These thresholds are currently placeholders and require validation against Scout terrain guidance.
